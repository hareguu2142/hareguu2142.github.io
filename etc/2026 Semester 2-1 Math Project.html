제출 방법

제출 사이트에서 평가 항목을 선택하고 작성한 파일을 업로드해주세요.

제출 사이트로 이동 →

  1. 정보 입력이름, 반 번호, 학생증 번호를 입력합니다.
  2. 평가 선택-선형근사를 통한 최적화 또는 -일상 속 계량경제 프로젝트-를 선택합니다.
  3. 파일 업로드각 과정평가별로 파일 1개를 선택합니다.
  4. 제출 및 확인제출 버튼을 누른 뒤 사이트 하단 검색에서 제출 파일을 확인할 수 있습니다.

재제출 안내: 같은 수행평가를 다시 제출하면 가장 나중에 제출한 파일이 반영됩니다.
